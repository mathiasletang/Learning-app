# Commencer ici

Bienvenue dans l'**Atelier**. Ce guide t'explique comment enchaîner les modules pour progresser efficacement.

## L'ordre conseillé

1. **Décodeur de notations** — pour lire sans bloquer sur les symboles.
2. **Série 0** — remise en route (gradient, hessienne, valeurs propres).
3. **Parcours Optimisation** — le cœur du travail, phase par phase.
4. **QCM** en mode entraînement, puis **révision** des erreurs en flashcards.

> Travaille par sessions de 45 minutes, avec le chronomètre du module **Temps**.

## Un rappel utile

La condition du premier ordre pour un minimum d'une fonction dérivable $f$ est $\nabla f(x^\star) = 0$.
Pour une fonction convexe, cette condition devient **suffisante**.
